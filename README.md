# Форма регистрации — учебный проект для семинара

Рабочая форма регистрации (телефон + пароль + подтверждение пароля) без сборки, чистый HTML/CSS/JS. Открывается прямо в браузере файлом `index.html`, никакой установки не требуется.

## Как использовать на занятии

1. Залейте этот проект в `main` — это ЭТАЛОННАЯ рабочая версия без багов.
2. Создайте 4 ветки от `main`, в каждой внесите один точечный баг (см. ниже) — это будут стартовые ветки для команд.
3. На занятии каждая команда получает свою ветку, копию репозитория (fork) или доступ на редактирование, и работает с ИИ, чтобы найти и исправить баг.
4. Каждая команда открывает Pull Request в `main`.
5. Вы по очереди мёржите PR, обновляете открытый `index.html` (или деплой) и показываете исправление на экране.

Автор: Валерия Юнусова. Рабочая ветка: `Group_4`.

### Найденный баг и исправление

Кнопка регистрации оставалась доступной даже при пустых полях, неверном телефоне или несовпадающих паролях: функция `updateSubmitButtonState()` всегда присваивала `submitBtn.disabled = false`.

Исправление в `script.js`:

```js
submitBtn.disabled = !isFormValid();
```

Теперь кнопка доступна только при корректном телефоне, допустимом пароле и совпадающем подтверждении. При отправке форма дополнительно проверяет данные.

### Запуск и проверка

Откройте `index.html` в браузере или запустите из каталога проекта:

```bash
python3 -m http.server 8000
```

Перейдите на http://localhost:8000.

1. Оставьте поля пустыми — кнопка недоступна.
2. Введите неверный телефон, короткий пароль или несовпадающее подтверждение — кнопка недоступна.
3. Введите телефон `+79991234567`, пароль `Abcdefg1` и такое же подтверждение — кнопка доступна.
4. Нажмите кнопку — появится сообщение об успехе.
5. Очистите любое поле — кнопка снова недоступна.

Это учебная демонстрация: аккаунты не создаются, данные не отправляются на сервер.

### Улучшения интерфейса

Обновлены цвета, отступы и оформление карточки. Добавлены адаптация для узких экранов, заметный фокус для клавиатуры, подсказки к полям, телефонный тип ввода и атрибуты автозаполнения. Сообщения об ошибках связаны с полями и объявляются скринридерам.
